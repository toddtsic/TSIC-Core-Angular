Before you pool

Incorporate national rankings to assist pool assignment

If you want pools built by strength rather than by guesswork, do this before step 1. USA Lacrosse › USA Lacrosse Rankings attaches published national ranking numbers to the teams registered in your event, and every number you save turns up as a sortable Nat'l column in Pool Assignment:

Doing it first is the whole point: with the column populated you sort by rank and snake the top teams across pools, so the strong ones don't stack up in one bracket. Doing it after pools are set means re-doing the assignment you just finished.

Two things to know going in. The ranking age groups are published by graduation class, so you pair each one with the age group in your event that holds those players — and for a new event, the most recently completed season is the one with a full year of results behind it. And the matcher is a best guess from club name, colour, grad year and state, so review every pairing, not just the weak ones; hand-matched teams are always saved regardless of the confidence level you pick.

Tournaments only, and read live from a site we don't control.

Matching registered teams exists to seed tournament pools, so it is offered on tournaments only — leagues can browse the published rankings but not attach them. The numbers are read live from usclublax.com, which can change or go offline, so check the results before you seed on them. Re-running is safe at any time: saving again overwrites.

Quickly create pools and optionally theme your event

Divisions are your pools, and their names follow the event everywhere — schedules, reports, the app. So settle them before you start moving teams. In Teams & Rosters › L-A-D-T Editor, the menu above the tree opens Theme Division Names: type one list of names and it applies to every age group at once — creating the divisions that do not exist yet and renaming the ones that do. Plain Pool A / Pool B / Pool C, or a theme for the tournament if you want one.

The panel underneath is a real dry run. Before you type it lists your Current Divisions; as soon as there are names it becomes a Preview, age group by age group, showing each rename, each division it would create, and each one it would remove. Nothing happens until Apply Theme.

A division holding teams is never removed.

If your list is shorter than an age group's existing divisions, the surplus ones would be removed — but only while they're empty. Any division with teams in it shows as has teams in the preview and is left alone, so this is safe to run on an event that's already partly pooled.
