Scheduling Checklist

This is your scheduling home — an ordered list of everything that has to happen before a schedule can be built, with live status. Each step shows exactly what's still missing (which age groups, which teams, which divisions) and links straight to the screen where you fix it. Work down the list top to bottom.

The build stays locked until the steps above it are green.

Teams left in the Unassigned pool can never be scheduled — the checklist won't let a build run that would silently skip them.

The steps, in order

1 · Assign Teams To Pools
Every team moves out of Unassigned into a real pool. The step lists each age group still holding unpooled teams.
2 · Assign Play Dates
Which dates each age group plays.
3 · Assign Fields
Which fields each age group plays on, with start times and game intervals.
4 · Set Game Guarantees
How many games each team is guaranteed. A division without a guarantee is skipped by the builder.
5 · Pairings
Who-plays-whom per pool size. Informational — anything missing is generated automatically at build time.
6 · Build Schedule
Unlocks when steps 1–4 are green. Opens the Schedule Hub to run the build.

After the build

  • The Tools section lights up once games exist: View Schedule, Master Schedule, Rescheduler, QA Results and more.
  • The checklist stays useful all event long — come back to confirm everything is still green after roster or pool changes.

Common mistakes

  • Ignoring a partially-red step. One age group with unpooled teams blocks the whole build — the step's detail line names it.
  • Skipping a step because it "looks" done. Trust the status — it reflects the real data, not your memory of setting it up.
