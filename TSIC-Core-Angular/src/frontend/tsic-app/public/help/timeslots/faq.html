Assign Timeslots

No slot, nowhere to put the game.

Timeslot capacity is what makes or breaks a build — and a play day with no slots at all produces no games and no error. Watch the warnings above the table.

What exactly is a timeslot?

One droppable game slot: a day, a field, and a start time. When the schedule builds, each game lands in an open slot. Create enough of them, across enough fields, to hold every game your event needs.

Why can't I click Set Up Timeslots?

This age group has no game dates yet. The days the setup dialog offers are derived from the dates in the card above — no dates, no days, nothing to configure. Add at least one date first, or clone dates in from another age group.

How do I edit a single row in the timeslot table?

You don't — the table is a read-out. Everything is set in the Edit Timeslots dialog: unticking a field on a day removes its slots, ticking it on another day creates them, and the start, interval and slots-per-field replace what used to be per-row editing. One way in means the table can never disagree with what's stored.

Do I have to set timeslots up for each pool separately?

No. Setup works at the age-group level and writes the slots to every pool in it. Pools only appear in the table's last column, so you can see which ones a given field/day row covers.

Why do the three counts above the table disagree?

They answer different questions. Game slots is how many games actually fit — the one to compare against your pairings. Field/day rows is what's on screen after folding. Pool timeslots is the raw stored count: fields × pools × days, which is what legacy displayed. Six pools sharing one field-hour is one game slot, not six.

A row is highlighted and says pools are missing. What does that mean?

That field, on that day, has timeslots for some of the age group's pools but not all of them. The pools without slots can't have games placed there. Open setup and save the day again to cover every pool.

What do Every (interval) and Slots / field control?

Every is the gap between game starts on a field — 60 minutes means 8:00, 9:00, 10:00. Slots / field is how many games that field runs on the day. Fields × slots is the day's total, and the dialog adds it up for you as you type.

What is the Rnd column on a game date?

The first round played on that date. Day 1 is Rnd 1; if three rounds run on Day 1 then Day 2 starts at Rnd 4. Each calendar date should have its own first round — the screen warns you when two dates share one, or when every date is still sitting on Round 1.

What do the +D, +W and +R buttons on a date do?

+D clones the date to the next day, +W to the same day next week, and +R clones it carrying the next round number. They're shortcuts for the two shapes most events have: a weekend, or a league that plays the same weekday for weeks.

Does Clone to another age group add to what's already there?

No — it replaces. If the target age group already has dates or timeslots, they're removed and these are put in their place; you'll get a confirmation naming how many are about to go. The upside is that cloning twice can't double anything up.

A field isn't getting any games. Why?

Most likely it has no timeslots on that day for this age group. A field must be both assigned to the event (in Manage Fields) and ticked for that day in setup. Check the day's section in the table — if the field isn't listed, it isn't in play.

It says there are timeslots on a day the age group doesn't play.

Those rows are dead — the builder only reads slots for days that appear in the game dates, so it will never look at them. Either add the matching game date, or let the next setup save clear them.

Tip: assign fields and settle pools first, then come here. The game-slot count only means something next to the games your pools and pairings actually need, and setup can only offer fields the event has been given.
