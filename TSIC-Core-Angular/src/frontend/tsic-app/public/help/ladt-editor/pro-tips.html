New fee features: Early Bird & Late Fee, per role

Fees are no longer one number. Every level can carry, separately for Players and Club Reps:

  • Fees — the base charge, shown as deposit–balance when two-phase
  • Early Bird — a discount that applies before the deadline you set
  • Late Fee — a surcharge that applies after its deadline
  • Payment Phase — pay-in-full vs deposit-first
Fees Player: $150–$350 Club Rep: $600
Early Bird Player: −$25 Late Fee Player: +$50
Payment Phase Player: Deposit Club Rep: PIF

All four appear as their own columns at every level of the grid, so a whole league's money posture is readable in one screen. Set them in the detail fly-in; read them here.

Where fees and phases come from

A team's real price can be set on the team, its division, its age group, or the league — the pills tell you which, at a glance:

  • Solid pill — the value is set at this level and operates here.
  • Dimmed pill — inherited from a level above; this row adds nothing.
  • ↓3 same — three overrides exist below, all agreeing with this value.
  • ↓2 varies — overrides below disagree — the row's number isn't the whole story. This is the pill to chase.
  • varies — no single value covers what's underneath; drill down to see the spread.

Hover any pill's and the tooltip names the exact source level and what happens below. A pill only ever claims a value that actually operates on someone — placeholder zeros don't masquerade as pricing.

Tip: the detail fly-in tells the same story — open any node and its fee cards show the resolved values with the same source context, right where you'd edit them.

Detail fly-in

Repricing: all registrations, or future only

Change a fee that touches people who already registered, and the save bar asks the question that matters before anything commits:

This change affects existing registrations.

  • Update all — retroactive: everyone already registered is repriced to the new amount. This is the default, because a fee correction usually should reach the people already in.
  • Future only — existing registrations keep the price they signed up under; only new registrations get the new amount.
  • Keep editing — backs out; nothing saves.

Flipping a payment phase is stricter: the flip reaches existing registrations only when you click Convert — Cancel reverts the toggle entirely.

Unsaved changes can't slip away

Edited a detail panel and clicked somewhere else? The fly-in won't silently discard your work — it stops and asks:

Discard unsaved changes?

This panel has changes you haven't saved. Leaving now will discard them.

So you can navigate the tree and grid freely mid-edit — the guard catches you before anything is lost, everywhere in this editor.
