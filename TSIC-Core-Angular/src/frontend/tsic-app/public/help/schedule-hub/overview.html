Schedule Hub

This is where the schedule gets built and managed. You arrive here from the Schedule button on step 4 of the Scheduling Checklist — the arrow at the top-left takes you back. The hub has three segments in one control at the top; each is a different job on the same event, and you move between them freely rather than in a fixed order.

Use a desktop.

The grid, drag-and-drop, and game placement need a full-size screen — the hub asks for a desktop browser rather than a phone or small tablet.

The three segments

Schedule
The working surface. Build games for the selected scope, then place any championship/bracket games onto the grid by hand.
QA
Conflict checks — a team double-booked, a field clash, a broken bracket — to run before you publish.
Master
The whole event on one grid — the view everyone else consumes, and where you export to Excel.

QA and Master are also listed as tools on the Scheduling Checklist. Those links land you right here on the matching segment — same screen, same chrome, whichever door you came through.

Setup lives on the checklist, not here

Everything the build reads — fields, pools, play dates, timeslots — is authored through the Scheduling Checklist steps before you arrive. The hub's setup check verifies it all again at build time and names anything missing. Game guarantees and placement rules are reviewed in the build flow itself.

Scope: Event, Age Group, or Division

In Schedule mode the navigator on the left lets you work at three levels. Build and delete always act on the scope you've selected:

Event → Age Group → Division

The Build button always names the current scope and reads Re-Build once that scope already has games. The scope you're in is shown in the breadcrumb above the grid.

Build the whole event first; build one division only to repair it.

Placing games is a contention problem — every age group is competing for the same field-hours. A full-event build sees all of that demand at once. Building a single division early lets it grab slots with no knowledge of what still has to fit, and you find out at the end. Single-scope builds are a repair tool for after a full build, not a way to work through the event a pool at a time.

Building the games

  • In Schedule mode, click Build (or Re-Build) to auto-generate round-robin games for the selected scope. A setup check runs first and, if anything is missing, lists it in a Setup incomplete panel — missing pairings can be generated right from that panel.
  • Championship / bracket games are placed by hand. After the round-robin build the hub switches you to the affected division and shows a banner — use Add Row to create a timeslot at the right interval, then drop each championship game onto it.
  • Two placement styles: mouse (click a game, click an open slot) or keyboard (Rapid Placement — type a field and a time). Your choice is remembered.
  • Not ready to place a championship game yet? Park it. Parked games move to the collapsible Parking section at the bottom of the grid and free their timeslots; drag them back individually when you are.

Common mistakes

  • Building before setup is done. If the setup check blocks you, the panel names what's missing. Fields, dates, timeslots, and pools are the usual culprits — and the Scheduling Checklist tracks all of them.
  • Building at the wrong scope. Check the scope name on the Build button — it's easy to rebuild one division when you meant the whole event, or vice-versa.
  • Walking away with championship games unplaced. Round-robin games build automatically; bracket games don't. If the banner is up, you still have games to place.

If you get stuck

Run QA before publishing — it surfaces conflicts you can't easily eyeball. If a build won't start, the setup-incomplete panel tells you exactly what's missing, and the Scheduling Checklist (back arrow, top-left) shows the same gaps as a work list.
