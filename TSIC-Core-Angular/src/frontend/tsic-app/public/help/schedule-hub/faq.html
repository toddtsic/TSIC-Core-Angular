Schedule Hub

If the Build button won't run, the event isn't fully configured yet.

Pools, dates, timeslots, and pairings all have to be in place first — the setup check tells you which one is missing, and the Scheduling Checklist tracks the same list as steps.

Where do I start on a brand-new event?

On the Scheduling Checklist, not here — it walks you through pooling teams, setting play dates and timeslots, and only then sends you to this screen to build. Within the hub, Configure pulses Start here when the event has no games; that's where the dates, fields, rules, and waves the builder reads all live.

What's the difference between the Schedule and Master segments?

Schedule is your working surface — you build and place games there, scoped to the event, an age group, or a single division. Master is the read view of the entire event on one grid: what players, coaches, and referees ultimately see, and where you export to Excel.

I clicked QA Results on the checklist and landed here instead. Why?

Because QA is a segment of this screen. Rather than maintain two versions of QA and Master with different chrome around them, the checklist's tools open the hub with the right segment already selected. Nothing is missing — the exports, the stats, and every check are all here.

I clicked Build but it only rebuilt one division. Why?

Build acts on the scope you have selected in the left navigator. If you're drilled into a division, the button reads Build/Re-Build for that division only — and it prints the scope name right on the button. Click Event at the top of the navigator to build everything at once.

Can I just build one age group at a time and work through the event?

Don't. Every age group is competing for the same field-hours, and the builder only knows about the demand in the scope you gave it — an age group built first will take the slots it likes with no idea what still has to fit around it. Build at Event scope, then use a single age group or division build to repair one piece afterwards.

It says the setup check needs pairings. Do I have to go set them up?

No — the Setup incomplete panel has a button that generates the missing pool sizes for you. Open Manage Pairings only if you want to review or customize the who-plays-whom pattern before generating.

My round-robin games built, but the championship games are missing.

That's expected — round-robin (pool) games generate automatically, but championship and bracket games are placed by hand so you control which slot each one lands in. The hub moves you to the affected division and shows a banner. Use Add Row to open a timeslot at the right time, then drop each game onto it.

I don't want to place the championship games yet.

Park them. Parking moves the championship games into a collapsible Parking section at the bottom of the grid and frees the timeslots they were holding. Expand it and drag them back individually when you're ready to place them for real.

Can I place games with the keyboard instead of dragging?

Yes. Switch to keyboard placement and clicking a game opens Rapid Placement, where you type to pick a field and a time. Prefer the mouse? Leave it on mouse mode and click the game, then click the open slot. Your preference is saved.

How do I clear a schedule and start over?

Delete acts on the selected scope — a single division, an age group, or (at event scope) the whole build. Deleting frees those games' timeslots so you can rebuild. Because it's scope-aware, double-check the scope label before you confirm.

This is a returning event — do I still need to touch Configure?

Yes. The hub carries last year's fields, dates, and waves forward for you, which saves the typing but is still a guess: it can't know that you took 40 more teams this year, or dropped a field. Every setting the builder reads is on one of the Configure tabs, and Config Summary shows them all in a single table for a fast review.

It's telling me I need pools or bracket seeds. Where are those?

Both open inside the hub from Configure, alongside Manage Fields, Manage Pairings and Assign Timeslots. Pool Assignment sorts teams within an age group into pools; Bracket Seeds sets the playoff seeding. Use the Back button in the toolbar to return to the segment you came from.

Why does it say I need a desktop?

The scheduling grid relies on drag-and-drop and precise placement that don't work well on a phone or small tablet. Open this screen on a laptop or desktop for the full experience.

Tip: always run QA before you publish. It catches the conflicts that are hard to spot by eye — a team booked twice in one slot, a field double-used — while they're still cheap to fix. It's one click away on the segment control.
