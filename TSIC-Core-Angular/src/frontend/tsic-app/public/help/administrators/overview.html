Administrators

This screen controls who can run this job — Directors, SuperDirectors, and the other admin roles. Every row is a real person with access to the job's sensitive data: player and family contact information, medical forms, payments, and accounting. Adding someone here is the single most powerful grant in the system, so the screen is SuperUser-only and deliberately picky about who it will accept.

Each admin role is its own lane — no cross-type grants.

An account is eligible for a role only if it has never held any other role, anywhere on the platform — or is a pending coach/staff adult registered with this customer. Director and SuperDirector count as one lane (two trust levels of the same person); Ref Assignor, Store Admin, and STPAdmin are each strictly their own. Family and player logins never qualify for anything — family credentials are shared within a household, and elevating one would hand admin access to everyone who knows the password, including the kids.

Adding an existing admin

Add Administrator → pick the role first — the search only looks inside that role's lane. Accounts badged Admin account already hold exactly this role (or its Director/SuperDirector sibling) elsewhere; selecting one pins them to this job with a new admin registration. A Director cannot be handed Store Admin, and a referee's account cannot become Ref Assignor — people wearing a new hat come through the funnel below with a fresh account.

Adding a brand-new person

Someone who has never held an admin role needs their own account first — never a shared family login. The path:

  • 1. They register as a coach/staff adult on this job's site (the adult registration flow), creating a personal account.
  • 2. They appear in this screen's search badged Pending adult.
  • 3. You accept them with the admin role you want. Their pending coach/staff registration is converted into the admin registration — one account, one registration, and they drop out of the coach-approval queue automatically.

Roles

  • Director — full admin for this job.
  • SuperDirector — Director plus cross-job powers within the customer.
  • Ref Assignor / Store Admin / STPAdmin — scoped admin roles for refereeing, the store, and STP.

ApiAuthorized is retired — direct third-party API access to player data is no longer offered. To share rosters with a third party, run the Third-Party Roster Export (Report Library) for age groups you've enabled, and provide it yourself.

Primary contact

The star marks the job's primary contact — the Director whose name goes out as the event's public point of contact. Every job has one: by default it's the earliest-registered active Director, set automatically. Click another active Director's star to hand it to them; click the starred row to revert to the default.

Active / Inactive

The status toggle suspends an admin without deleting them — useful between seasons. Activate All / Deactivate All act on every non-SuperUser row at once.

Common mistakes

  • Trying to add a parent's family login. It won't be offered, and the server will refuse it. If a parent should be a Director, have them create their own coach/staff account on the site first — the household keeps its family login for the kids, and the admin role rides on personal credentials.
  • Expecting a just-registered coach to keep their coach spot. Accepting a Pending adult here converts that registration to the admin role — it's an either/or, not both.
