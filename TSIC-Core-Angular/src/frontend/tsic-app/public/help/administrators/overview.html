Administrators

This screen controls who can run this job — Directors, SuperDirectors, and the other admin roles. Every row is a real person with access to the job's sensitive data: player and family contact information, medical forms, payments, and accounting. Adding someone here is the single most powerful grant in the system, so the screen is SuperUser-only and deliberately picky about who it will accept.

Only two kinds of accounts can be added.

Admin accounts (people who already hold admin roles and nothing else) and pending coach/staff adults registered with this customer. Family and player logins never appear in the search and are rejected by the server — family credentials are shared within a household, and elevating one would hand Director access to everyone who knows the password, including the kids.

Adding an existing admin

Add Administrator → search by name or username. Accounts badged Admin account already hold admin roles elsewhere; selecting one and choosing a role pins them to this job with a new admin registration.

Adding a brand-new person

Someone who has never held an admin role needs their own account first — never a shared family login. The path:

  • 1. They register as a coach/staff adult on this job's site (the adult registration flow), creating a personal account.
  • 2. They appear in this screen's search badged Pending adult.
  • 3. You accept them with the admin role you want. Their pending coach/staff registration is converted into the admin registration — one account, one registration, and they drop out of the coach-approval queue automatically.

Roles

  • Director — full admin for this job.
  • SuperDirector — Director plus cross-job powers within the customer.
  • Ref Assignor / Store Admin / STPAdmin / ApiAuthorized — scoped admin roles for refereeing, the store, STP, and API access.

Primary contact

The star marks the job's primary contact — the Director whose name goes out as the event's public point of contact. One per job; click to set, click again to clear.

Active / Inactive

The status toggle suspends an admin without deleting them — useful between seasons. Activate All / Deactivate All act on every non-SuperUser row at once.

Common mistakes

  • Trying to add a parent's family login. It won't be offered, and the server will refuse it. If a parent should be a Director, have them create their own coach/staff account on the site first — the household keeps its family login for the kids, and the admin role rides on personal credentials.
  • Expecting a just-registered coach to keep their coach spot. Accepting a Pending adult here converts that registration to the admin role — it's an either/or, not both.
