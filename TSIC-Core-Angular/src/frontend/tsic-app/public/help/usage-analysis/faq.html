Usage Analysis

Why can't I pick Customer or All TSIC?

Scope follows role. A Director sees the event they are signed into; a SuperDirector adds the customer's other live events; only a Superuser sees the whole platform. The server enforces the same ceiling, so the segment simply doesn't offer what your role can't hold.

The page says "This event has concluded."

Usage analysis covers live events only — those whose registration window is still open. Once an event concludes it drops out of every scope, including its own. Switch to Customer or All TSIC if your role allows it; the concluded event won't be in those either.

"Usage logging is not configured on this server."

The usage database isn't connected on the server you're using. That is a missing data source, not "nobody used anything" — the page says so rather than showing an empty chart.

Do these numbers include the mobile apps?

Yes — every request to the platform is logged, whichever app made it. A request is attributed to an event when the app names it, which the web app and the mobile apps all do for event-specific screens. A handful of calls are genuinely event-less (signing in, listing all events) and are not counted under any event.

A report just shows its name and "nothing here yet."

That report is a reserved slot — its question is decided but its report isn't built yet. The scope, window and bot controls already apply to it, which is why it shows the query it would run.
