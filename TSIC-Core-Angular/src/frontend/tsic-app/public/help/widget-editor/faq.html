Widget Editor

One event, or every event?

That's the question behind almost everything on this screen. Job Overrides changes one event. Default Matrix and Role Assignments change every event of a job type.

How do I tell whether a widget is switched on for the event I'm in?

The In Use column on Widget Definitions tells you how many events have it, but not which ones. For a definite answer about the event you're in, click the green job count — or open Job Overrides, which starts on your current event — and look at that widget's row.

How do I remove a widget from one event?

In Job Overrides, use the at the end of that widget's row, then Save Overrides. You can also right-click an individual checkbox to undo just that one role.

Unticking a box is not the same thing. That records "switched off for this event" and keeps the row. Both hide the widget; the row button leaves things cleaner.

I added one widget and the rest of the Dashboard changed. Why?

An event with no widgets assigned shows a standard Dashboard — banner and bulletins. The moment it has even one assignment, it switches to showing exactly what's assigned, and the standard layout stops applying.

If you want the old panels back alongside your new widget, assign them explicitly too.

What does "Not in use" mean? Is it broken?

No. It means the widget is defined but no event and no automatic rule uses it, so nobody currently sees it. That's normal for something just built and not yet rolled out.

There's a warning about a widget not being set up. What is it telling me?

A developer has built that widget, but it has no definition here — so it can't be added to any event yet. Click it to create the definition, which opens the Add Widget form already filled in.

Don't treat it as a to-do list. If you're not sure a widget is wanted, leave it. Setting up something that was replaced by a newer panel just puts a duplicate on the page.

Why can't I delete a widget?

Because something still uses it. Clear its assignments first — the automatic rules in Default Matrix and any per-event entries in Job Overrides — then delete it.

The In Use column shows you what's holding it.

What is the Component Key, and what happens if I invent one?

It's the link between this definition and the code a developer wrote. Pick from the list and it's guaranteed to match.

If you type a custom key with no matching code, the widget saves without complaint and then renders as blank space on every event you add it to. There's no error — just an empty gap. Only use a custom key when a developer has told you the name to use.

What's the difference between Role Assignments and Job Overrides?

Role Assignments (inside the Add/Edit Widget dialog) creates automatic rules. Tick a job type there and every event of that type gets the widget — existing and future.

Job Overrides changes one event only. If you meant "just this one tournament," that's the tab you want.

Can a Director change their own widgets?

They can show, hide, and reorder widgets on their own Dashboard through customize — that's personal to their login and doesn't affect anyone else.

They cannot add or remove widgets from the event. This screen is SuperUser only.

What does the drag handle do?

It sets the order widgets appear in on the Dashboard, within their category. Drag a row up or down, then Save Overrides.

Does any of this affect the public event page?

Not currently. Widgets in the public workspace can be defined and assigned, but the public page shows its banner and bulletins from a fixed layout rather than from these settings. Switching a public widget off here will not change what visitors see.
