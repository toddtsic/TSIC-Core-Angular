A request is one API call made by someone signed in. Role is the one they were registered under; a family account working without a registration (the player registration wizard) is Family, and any other login without one is No registration. People are counted by registration, or by login where there was none. Routes are the API endpoint (Controller/Action), not the page: one page fires several. Page-shell requests — loaded on arrival in any page, whatever page it is — are counted in their tile and left out of the routes. Home page (bulletins) is the event's home page loading its bulletins. The chart draws the busiest routes; the Every route table lists them all. Requests that failed are counted in the tile and the Failed columns, never in the chart.
