A user is a registration that made at least one request about the event in that day, week or month, and counts again in every other bucket it was active in — so the buckets do not add up to report 01's total for the span. Someone holding two roles counts once under each. An event counts only in the buckets it was live in, so an event that concluded during the span is in the older buckets and not the newer ones. The newest bucket is the current one, still filling.
