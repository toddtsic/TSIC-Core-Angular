A request is one API call made with no one signed in — the public, and anyone browsing before they sign in. Routes are the API endpoint (Controller/Action), not the page: one page fires several. Page-shell requests — loaded on arrival in any page, whatever page it is — are counted in their tile and left out of the routes. Home page (bulletins) is the event's home page loading its bulletins. The chart draws the busiest routes; the Every route table lists them all. Requests that failed are counted in the tile and the Failed columns, never in the chart.
