An export is one successful run of the Authorized Rosters and Schedule Export — the whole roster of every age group the event has released, plus its schedule, downloaded as a file that then lives outside TSIC. Runs that were refused are not counted: they exported nothing. The rosters are gated per age group by Third-Party Roster Access in the L-A-D-T Editor; the schedule tab is the whole event and is not gated, because schedules are public. This report counts runs, not what was in them: which age groups a given run carried is not recorded anywhere. Each event is a group of monthly bars, yyyy/mm: a month nobody exported in is not a column at all, and a month one event sat out is a gap in its group rather than a zero. Third party is an outside agency signed in with an export-only login; any other role is one of the event's own administrators running the same export. Events that exported nothing are left out rather than drawn as zero.
