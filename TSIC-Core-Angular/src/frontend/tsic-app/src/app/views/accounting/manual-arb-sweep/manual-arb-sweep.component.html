Manual ARB Sweep

Pulls Authorize.Net settled batches for the last N days: books new ARB charges, stamps eCheck settlement confirmations (status only — eCheck money books at submit), and reverses eCheck returns. Also runs the stale-draft watchdog, flags orphan charges — money settled at Authorize.Net with no local accounting row — reports untracked eCheck payments (review only; never auto-booked), and emails the family behind every recurring draft that failed. Mirrors the nightly background sweep but runs on demand; refuses to start if a sweep is already running.
